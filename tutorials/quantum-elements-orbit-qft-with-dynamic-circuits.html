Benchmark věrnosti procesu QFT pomocí Orbit, funkce Qiskit od Quantum Elements

Odhad využití: 2 minuty na procesoru Heron r3. (POZNÁMKA: Toto je pouze odhad. Tvůj skutečný čas se může lišit.) Ve výchozím nastavení tento tutoriál odešle jednu úlohu Orbit Function pomocí serverového Runtime Batch služby IBM Quantum Compute Service se třemi podřízenými úlohami, 300 PUB na podřízenou úlohu a celkem 921 600 shotů.

Varování: Dynamické obvody jsou v současnosti experimentální funkcí a podléhají omezením ve službě Quantum Compute [3], která mohou způsobit selhání úloh. Například chyba 6073 znamená, že úloha překročila limit paměti klasického řídicího hardwaru [4]. Tento notebook toto riziko snižuje rozdělením velikostí obvodů do tří podřízených úloh Runtime Batch [5]. Každé porovnání pro pevnou velikost zůstává v jedné podřízené úloze, zatímco velké a malé velikosti jsou spárovány tak, aby vyvážily zátěž klasického řízení mezi úlohami.

Výstupy z učení​

  • Připravit součinové (produktové) stavy QFT†∣x⟩\mathrm{QFT}^\dagger|x\rangleQFT†∣x⟩ používané vzorkovaným odhadem věrnosti procesu na obrázku 2a v ref. [1].

  • Sestavit ekvivalentní unitární a dynamické implementace kvantové Fourierovy transformace následované měřením.

  • Vybrat fyzické qubity pro dynamické obvody pomocí aktuálních dat o kalibraci a konektivitě.

  • Porovnat odhady věrnosti procesu QFT pro surovou unitární, surovou dynamickou a Orbit-vylepšenou dynamickou variantu s rostoucí velikostí obvodu.

  • Odeslat jednu pracovní zátěž Orbit pomocí API batch mode, přičemž každé porovnání tří strategií pro danou velikost zůstane v jedné podřízené úloze.

  • Prozkoumat metadata Orbit pro potvrzení, zda byla použita dynamická decoupling (DD) a zmírnění chyb měření (MEM).

Souvislosti​

Obrázek 2a v ref. [1] porovnává věrnost procesu ideálního kanálu QFT+M se zašuměnými unitárními a dynamickými implementacemi. Pro vzorkovaný štítek xxx v základní výpočetní bázi benchmark připraví QFT†∣x⟩\mathrm{QFT}^\dagger|x\rangleQFT†∣x⟩, aplikuje zašuměnou implementaci QFT+M a odhadne pravděpodobnost pxp_xpx​ získání odpovídajícího ideálního výstupu. Tyto stavy inverzní QFT jsou separovatelné a lze je efektivně připravit pomocí Hadamardových hradel a virtuálních fázových rotací.

Pro mmm nezávisle vzorkovaných štítků notebook používá nezkreslený odhad odvozený v ref. [1]:

F^proc=mm−1(1m∑ℓ=1mpxℓ)2−1m(m−1)∑ℓ=1mpxℓ.\widehat{\mathcal{F}}_{\mathrm{proc}} = \frac{m}{m-1}\left(\frac{1}{m}\sum_{\ell=1}^{m}\sqrt{p_{x_\ell}}\right)^2 - \frac{1}{m(m-1)}\sum_{\ell=1}^{m}p_{x_\ell}.Fproc​=m−1m​(m1​ℓ=1∑m​pxℓ​​​)2−m(m−1)1​ℓ=1∑m​pxℓ​​.

Dynamická konstrukce nahrazuje řízená fázová hradla unitární QFT+M měřeními uprostřed obvodu a klasicky podmíněnými fázovými rotacemi [1]. Díky odloženému měření mají oba obvody stejné ideální výstupní rozdělení. Unitární implementace vyžaduje dvoukubitová hradla mezi všemi dvojicemi a kvůli omezením lokální konektivity vede k režii O(n2)O(n^2)O(n2) hradel SWAP. Naproti tomu dynamický obvod používá pouze jednokubitová hradla a O(n)O(n)O(n) měření uprostřed obvodu, která uprostřed zavádějí dlouhé prodlevy. Pokud zcela pomineme DD, jde v podstatě o soutěž mezi O(n2)O(n^2)O(n2) zašuměných unitárních hradel a O(n)O(n)O(n) zašuměných měření uprostřed obvodu. Pokud jsou prodlevy během těchto měření uprostřed obvodu dostatečně málo chybové, dynamický obvod překoná unitární implementace, a níže ukážeme, že toho lze dosáhnout pomocí Orbit.

Vztah k obrázku 2a. Tento notebook se řídí protokolem vzorkované věrnosti procesu z článku, ale jde spíše o adaptaci tutoriálu zaměřenou na Orbit než o reprodukci. Například zatímco obrázek 2a používal ibm_kyiv s 2000 shoty, my používáme moderní zařízení ibm_aachen s menším počtem 1024 shotů, abychom šetřili čas QPU.

Nastavení​

Přihlas se k IBM Quantum® Platform, načti ibm_aachen a načti Quantum Elements Orbit z Qiskit Functions Catalog.

N_VALUES je seznam velikostí obvodů: každá hodnota je počet logických qubitů v jednom obvodu QFT. M je počet nezávisle vzorkovaných bázových popisků xxx vyhodnocených pro každou velikost; v odhadu věrnosti je to mmm ve výše uvedené rovnici. Pro každou dvojici (N, x) notebook odešle jeden PUB pro každou ze tří strategií, takže pevná velikost přispívá 3 * M PUB a 3 * M * SHOTS shotů obvodu.

Výchozí průchod parametry tedy vyhodnocuje 15 velikostí obvodů, 20 vzorkovaných bitových řetězců na velikost a tři strategie. NUM_BATCH_PARTITIONS=3 určuje tři uspořádané oddíly Runtime Batch a BATCH_MAX_PUBS_PER_JOB se předává přes orbit.run(...) jako konfigurace JSON. Velké N_VALUES vytvářejí složitější dynamické obvody, zatímco větší M umísťuje více PUB do každé podřízené úlohy; obojí může zvýšit zátěž paměti klasického řízení Backendu. Pokud jednotlivá podřízená úloha s dynamickým obvodem dosáhne tohoto limitu, sniž N_VALUES nebo M, nebo zvyš NUM_BATCH_PARTITIONS. Sniž SHOTS, pokud je cílem snížit spotřebu provedení, nikoli počet nebo složitost obvodů.

OPTIMIZATION_LEVEL=0 žádá transpiler Qiskit, aby provedl nutný překlad a směrování s minimální optimalizací. Používáme to, abychom zachovali explicitně zvolená rozložení dynamických obvodů a usnadnili interpretaci surových srovnání. Úrovně 1–3 jsou platné experimenty, ale mohou obvody přepisovat nebo zjednodušovat a mohou změnit zvolené umístění; zde se od nich očekává jen malý přínos, protože dynamický obvod nemá žádná dvoukubitová hradla ani omezení konektivity. Pokud úroveň změníš, spusť benchmark znovu a výsledky ber jako samostatné srovnání.

def balanced_n_groups(
    n_values: list[int], num_jobs: int = 3
) -> list[list[int]]:
    """Pair circuit sizes into balanced Runtime Batch partitions."""
    values = sorted(n_values)
    if len(set(values)) != len(values):
        raise ValueError("N_VALUES must not contain duplicates")
    if not 1 <= num_jobs <= len(values):
        raise ValueError(
            "NUM_BATCH_PARTITIONS must be between 1 and len(N_VALUES)"
        )

    max_group_size = (len(values) + num_jobs - 1) // num_jobs
    groups = [[] for _ in range(num_jobs)]
    loads = [0] * num_jobs
    pair_counts = [0] * num_jobs
    remaining = values.copy()

    while len(remaining) >= 2:
        candidates = [
            i
            for i, group in enumerate(groups)
            if len(group) + 2 <= max_group_size
        ]
        if not candidates:
            break
        smallest = remaining.pop(0)
        largest = remaining.pop()
        job_index = min(
            candidates, key=lambda i: (loads[i], len(groups[i]), i)
        )
        pair = (
            [largest, smallest]
            if pair_counts[job_index] % 2 == 0
            else [smallest, largest]
        )
        groups[job_index].extend(pair)
        loads[job_index] += smallest + largest
        pair_counts[job_index] += 1

    while remaining:
        value = remaining.pop()
        candidates = [
            i for i, group in enumerate(groups) if len(group) < max_group_size
        ]
        job_index = min(
            candidates, key=lambda i: (loads[i], len(groups[i]), i)
        )
        groups[job_index].append(value)
        loads[job_index] += value

    return groups

Sestavení obvodů QFT​

Pro každé vzorkované celé číslo xxx bit_inv_qft připraví součinový stav QFT†∣x⟩\mathrm{QFT}^\dagger|x\rangleQFT†∣x⟩ pomocí Hadamardových hradel následovaných fázovými rotacemi. Notebook poté přidá buď standardní unitární QFT, nebo její semiklasický dynamický ekvivalent QFT.

Obě implementace vynechávají závěrečnou síť prohození (swap). Pořadí zobrazení klasických bitů v Qiskitu proto způsobuje, že očekávaný naměřený řetězec je obrácením binárního zápisu xxx doplněného nulami, který je kódován výrazem format(x, f"0{n}b")[::-1].

def bit_inv_qft(circuit: QuantumCircuit, x: int, conv: str = "LSB") -> None:
    """Prepare QFT†|x⟩ as a product state on `circuit`."""
    num_qubits = circuit.num_qubits
    circuit.h(range(num_qubits))
    for j in range(num_qubits):
        phase = (
            2 * np.pi * x / 2 ** (num_qubits - j)
            if conv == "LSB"
            else 2 * np.pi * x / 2 ** (j + 1)
        )
        circuit.p(-phase, j)

def build_unitary_qft_circuit(num_qubits: int, x: int) -> QuantumCircuit:
    """Build a unitary QFT circuit for sampled basis label `x`."""
    if not 0 <= x < 2**num_qubits:
        raise ValueError(
            f"x={x} is outside the {num_qubits}-qubit basis range"
        )
    qreg = QuantumRegister(num_qubits, "q")
    creg = ClassicalRegister(num_qubits, "c")
    circuit = QuantumCircuit(qreg, creg, name=f"unitary_qft_{num_qubits}q")
    bit_inv_qft(circuit, x)
    circuit.append(
        synth_qft_full(num_qubits, do_swaps=False), range(num_qubits)
    )
    circuit.measure(range(num_qubits), range(num_qubits))
    return circuit

def _warn_if_precision_loss(max_num_entanglements: int) -> None:
    """Warn when the smallest QFT rotation may lose float precision."""
    if max_num_entanglements > -np.finfo(float).minexp:
        warnings.warn(
            "precision loss in QFT."
            f" The rotation needed to represent {max_num_entanglements} entanglements"
            " is smaller than the smallest normal floating-point number.",
            category=RuntimeWarning,
            stacklevel=4,
        )

def synth_dynamic_qft(
    circuit: QuantumCircuit, *, do_swaps: bool = False
) -> QuantumCircuit:
    """Append semiclassical dynamic QFT operations to `circuit`."""
    num_qubits = circuit.num_qubits
    creg = circuit.cregs[0]
    _warn_if_precision_loss(num_qubits - 1)

    for j in reversed(range(num_qubits)):
        circuit.h(j)
        circuit.measure([j], [j])

        if j > 0:
            with circuit.if_test((creg[j], 1)):
                for k in reversed(range(j)):
                    circuit.p(np.pi * (2.0 ** (k - j)), k)

    if do_swaps:
        for i in range(num_qubits // 2):
            circuit.swap(i, num_qubits - i - 1)
    return circuit

def build_dynamic_qft_circuit(num_qubits: int, x: int) -> QuantumCircuit:
    """Build a dynamic QFT circuit for sampled basis label `x`."""
    if not 0 <= x < 2**num_qubits:
        raise ValueError(
            f"x={x} is outside the {num_qubits}-qubit basis range"
        )
    qreg = QuantumRegister(num_qubits, "q")
    creg = ClassicalRegister(num_qubits, "c")
    circuit = QuantumCircuit(qreg, creg, name=f"dynamic_qft_{num_qubits}q")
    bit_inv_qft(circuit, x)
    synth_dynamic_qft(circuit, do_swaps=False)
    return circuit

def target_output_bitstring(x: int, n_qubits: int) -> str:
    """Return Qiskit's expected measured bitstring for basis label `x`."""
    return format(int(x), f"0{n_qubits}b")[::-1]

def process_fidelity_from_success_probabilities(
    success_probabilities: list[float],
) -> float:
    """Estimate process fidelity from sampled success probabilities."""
    m = len(success_probabilities)
    if m <= 1:
        raise ValueError(
            "m must be larger than 1 for the process-fidelity estimator"
        )
    succ = np.asarray(success_probabilities, dtype=float)
    return float(
        (m / (m - 1)) * (np.mean(np.sqrt(succ)) ** 2)
        - np.sum(succ) / (m * (m - 1))
    )

Výběr fyzických qubitů pro dynamický obvod​

Dynamická implementace nevyžaduje dvouqubitová hradla, takže její fyzické qubity nemusí tvořit propojený podgraf. Pro každou velikost obvodu selektor seřadí aktuální qubity backendu podle skóre váženého z 80 % nižší chybou čtení a z 10 % vyšším T1T_1T1​ a T2T_2T2​. Nejprve pokud možno vybírá vysoce hodnocené qubity bez přímých spojení mezi sebou, což může snížit expozici vůči přeslechům mezi sousedy, a poté doplní zbývající pozice podle skóre.

Varianty dynamic/raw a dynamic/orbit používají pro danou velikost přesně stejné vybrané rozvržení, takže rozvržení je v jejich porovnání pevně dané. Obvod unitary/raw je naopak mapován a směrován transpilátorem, protože vyžaduje dvouqubitovou konektivitu. Tento výběr založený na kalibraci za běhu je specifický pro tento tutoriál; nejde o pevné rozvržení s 40 qubity ibm_kyiv použité v experimentech k obrázku 2a v článku.

def value_from_property(raw):
    """Extract a numeric value from a backend property record."""
    if raw is None:
        return None
    if isinstance(raw, tuple):
        return raw[0]
    return getattr(raw, "value", raw)

def qubit_property_value(properties, qubit: int, *names: str) -> float | None:
    """Read the first available backend property for one qubit."""
    for name in names:
        try:
            value = value_from_property(
                properties.qubit_property(qubit, name)
            )
        except Exception:
            value = None
        if value is not None:
            return float(value)
    return None

def measurement_error(properties, qubit: int) -> float | None:
    """Return readout error, deriving it from asymmetric errors if needed."""
    readout = qubit_property_value(properties, qubit, "readout_error")
    if readout is not None:
        return readout
    p01 = qubit_property_value(properties, qubit, "prob_meas0_prep1")
    p10 = qubit_property_value(properties, qubit, "prob_meas1_prep0")
    if p01 is not None and p10 is not None:
        return 0.5 * (p01 + p10)
    return None

def coupling_edges(backend) -> list[tuple[int, int]]:
    """Return directed coupling-map edges as integer pairs."""
    coupling_map = getattr(backend, "coupling_map", None)
    if coupling_map is not None:
        try:
            return [(int(a), int(b)) for a, b in coupling_map.get_edges()]
        except Exception:
            pass
    built = backend.target.build_coupling_map()
    return [(int(a), int(b)) for a, b in built.get_edges()]

def neighbor_map(backend) -> dict[int, set[int]]:
    """Build an undirected neighboring-qubit map from backend connectivity."""
    neighbors = {qubit: set() for qubit in range(backend.num_qubits)}
    for a, b in coupling_edges(backend):
        neighbors[a].add(b)
        neighbors[b].add(a)
    return neighbors

def anchored_score(
    value: float | None, *, good: float, bad: float, higher_is_better: bool
) -> float:
    """Normalize a calibration value to a [0, 1] quality score."""
    if value is None:
        return 0.0
    if higher_is_better:
        low, high = sorted((bad, good))
        score = (value - low) / (high - low)
    else:
        low, high = sorted((good, bad))
        score = (high - value) / (high - low)
    return float(min(1.0, max(0.0, score)))

def qubit_metrics(backend) -> list[dict]:
    """Collect and rank calibration metrics for all backend qubits."""
    properties = backend.properties()
    rows = []
    for qubit in range(backend.num_qubits):
        t1 = qubit_property_value(properties, qubit, "T1", "t1")
        t2 = qubit_property_value(properties, qubit, "T2", "t2")
        meas_error = measurement_error(properties, qubit)
        measurement_score = anchored_score(
            meas_error, good=0.005, bad=0.05, higher_is_better=False
        )
        t1_score = anchored_score(
            t1, good=0.00025, bad=0.00005, higher_is_better=True
        )
        t2_score = anchored_score(
            t2, good=0.00025, bad=0.00005, higher_is_better=True
        )
        rows.append(
            {
                "qubit": qubit,
                "t1": t1,
                "t2": t2,
                "measurement_error": meas_error,
                "score": 0.8 * measurement_score
                + 0.1 * t1_score
                + 0.1 * t2_score,
            }
        )
    return sorted(rows, key=lambda row: row["score"], reverse=True)

def select_dynamic_qubits(backend, n_qubits: int) -> list[int]:
    """Choose high-scoring, preferably nonadjacent qubits for dynamic circuits."""
    ranked = qubit_metrics(backend)
    neighbors = neighbor_map(backend)
    selected = []
    blocked = set()
    for row in ranked:
        qubit = row["qubit"]
        if qubit in blocked:
            continue
        selected.append(qubit)
        blocked.add(qubit)
        blocked.update(neighbors.get(qubit, set()))
        if len(selected) == n_qubits:
            return selected

    for row in ranked:
        qubit = row["qubit"]
        if qubit not in selected:
            selected.append(qubit)
        if len(selected) == n_qubits:
            return selected
    raise RuntimeError(f"Could not select {n_qubits} physical qubits")

Příprava benchmarkových PUB​

Pro každou dvojici (N, x) notebook nejprve transpiluje logické obvody a vytvoří jeden Sampler PUB pro každou strategii:

  • unitary/raw: unitární QFT na rozvržení vybraném transpilátorem, se směrováním dle potřeby a bez Orbit DD nebo MEM.

  • dynamic/raw: dynamický QFT na fyzických qubitech vybraných na základě kalibrace, bez Orbit DD nebo MEM.

  • dynamic/orbit: stejný transpilovaný dynamický obvod na stejných fyzických qubitech, se zapnutým Orbit DD a MEM.

Orbit-vylepšený PUB používá transpilation_mode="validate", protože jeho mapování již bylo zvoleno. Orbit ověří dodaný fyzický obvod místo jeho přemapování a poté aplikuje svůj pipeline DD a MEM. Protože pouze vylepšená dynamická křivka požaduje MEM, nemělo by se to interpretovat jako izolované porovnání DD versus bez DD.

def extract_counts(pub_result) -> dict[str, int]:
    """Extract the first nonempty classical-register counts mapping."""
    data = getattr(pub_result, "data", None)
    if data is None:
        raise TypeError("pub_result.data is missing")

    for name in dir(data):
        if name.startswith("_"):
            continue
        register = getattr(data, name)
        get_counts = getattr(register, "get_counts", None)
        if callable(get_counts):
            counts = get_counts()
            if counts:
                return counts

    raise TypeError(
        "No classical register with get_counts() found in pub_result.data"
    )

def extract_raw_counts(pub_result) -> dict[str, int]:
    """Extract unmitigated counts from Orbit metadata when available."""
    orbit_metadata = pub_result.metadata.get("quantum_elements_orbit", {})
    mem_report = orbit_metadata.get("measurementErrorMitigation", {})
    return mem_report.get("rawCounts") or extract_counts(pub_result)

def probability_for_bitstring(
    counts: dict[str, int], bitstring: str, n_qubits: int
) -> float:
    """Return observed probability of an expected bitstring."""
    total = sum(counts.values())
    if total <= 0:
        return 0.0
    normalized = Counter()
    for measured, count in counts.items():
        key = measured.replace(" ", "")[-n_qubits:].zfill(n_qubits)
        normalized[key] += count
    return float(normalized.get(bitstring, 0) / total)

Kontrola metadat Orbit DD​

Shrnutí níže kontroluje metadata PUB dynamic/orbit namísto předpokladu, že požadovaný DD byl vložen. Zkontroluj stav, hlášenou dynamickou sekvenci DD, varování a počty vyplněných mezer a přidaných sekvencí. Úspěšné vložení by mělo přinést nenulové počty alespoň u některých PUB, ale přesné hodnoty závisí na naplánovaném obvodu, časových omezeních backendu a velikosti obvodu. Tato metadata popisují sekvenci aplikovanou Orbit; neměla by být označována jako protokol FC-DD z článku, pokud zpráva výslovně nepotvrzuje tuto ekvivalenci.

Vykreslení křivek věrnosti procesu​

Graf zobrazuje bodový odhad vzorkované věrnosti procesu QFT v závislosti na počtu qubitů pro tři strategie. dynamic/raw a dynamic/orbit sdílejí pro každou velikost fyzické rozvržení; unitary/raw používá rozvržení a směrování transpilátoru.

Na rozdíl od obrázku 2a tento graf nezobrazuje křivku unitární s DD ani pásy nejistoty a jeho surové křivky nejsou korigovány na chyby čtení. Nejlépe se čte jako srovnání škálování ve stylu obrázku 2a pro tento pracovní postup Orbit, nikoli jako přímá reprodukce publikovaných křivek.

from datetime import datetime
from zoneinfo import ZoneInfo

finished_local = datetime.now(ZoneInfo("America/Los_Angeles"))
labels = ["dynamic/orbit", "dynamic/raw", "unitary/raw"]
colors = {
    "dynamic/orbit": "#26735b",
    "dynamic/raw": "#9b1c31",
    "unitary/raw": "#6e6e6e",
}
pretty_labels = {
    "dynamic/orbit": "Dynamic QFT with Orbit",
    "dynamic/raw": "Dynamic QFT",
    "unitary/raw": "Unitary QFT",
}

series = []
for label in labels:
    values = [process_fidelity[str(n)][label] for n in N_VALUES]
    log_values = [value if value > 0.0 else float("nan") for value in values]
    series.append((label, values, log_values))

nonzero_values = [
    value
    for _, _, log_values in series
    for value in log_values
    if value > 0.0
]
if not nonzero_values:
    raise RuntimeError(
        "No nonzero process-fidelity values found for log inset"
    )
log_floor = min(nonzero_values) / 2

fig, ax = plt.subplots(figsize=(9.8, 5.6))
for label, values, _ in series:
    ax.plot(
        N_VALUES,
        values,
        marker="o",
        linewidth=2.0,
        markersize=5,
        color=colors[label],
        label=pretty_labels[label],
    )

ax.set_xlabel("N qubits")
ax.set_ylabel("Process fidelity")
finished_time_for_title = finished_local
ax.set_title(
    f"Dynamic QFT Orbit results on {IBM_BACKEND_NAME}\n"
    f"Job finished {finished_time_for_title:%Y-%m-%d %H:%M %Z}"
)
ax.set_xticks(N_VALUES)
ax.set_ylim(bottom=0)
ax.grid(axis="both", alpha=0.25)
ax.legend(loc="upper right")

inset = ax.inset_axes([0.53, 0.31, 0.44, 0.43])
for label, _, log_values in series:
    inset.plot(
        N_VALUES,
        log_values,
        marker="o",
        linewidth=2.0,
        markersize=5,
        color=colors[label],
    )
inset.set_yscale("log")
inset.set_ylim(bottom=log_floor)
inset.set_xlim(min(N_VALUES), max(N_VALUES))
inset.set_title("Log scale; zeros omitted", fontsize=9)
inset.grid(axis="both", alpha=0.25)
inset.tick_params(axis="both", labelsize=8)
inset.patch.set_alpha(0.96)

fig.tight_layout()
plt.show()
