Qiskit Functions

Červenec 2026​

  • Nové předběžné kontroly a nové metody backend v Qiskit Functions v0.17.0: Nové metody v qiskit-ibm-catalog ti umožňují zkontrolovat kapacitu runtime a přístup k backendu před spuštěním a run() nyní ověřuje obojí, než odešle úlohu.

    • Co je nového

      • Když zavoláš run() na funkci, služba nejprve zkontroluje tři věci: že tvá instance má kapacitu runtime, že se dostaneš k backendu, který jsi zadal, a že je dostupný alespoň jeden backend. Pokud je něco v pořádku špatně, dostaneš okamžitě jasnou chybu místo čekání ve frontě.

        Tyto zdroje si můžeš také kdykoliv zkontrolovat sám:

        • Zkontroluj svou zbývající kapacitu runtime pomocí usage().

        • Vypiš backendy, ke kterým se tvá instance dostane, pomocí backends().

        • Vyhledej konkrétní backend a ověř přístup pomocí backend().

        • Najdi backend s nejmenším počtem čekajících úloh pomocí least_busy().

    • Běžné případy použití

      • Zkontroluj svou zbývající kapacitu před dlouhou dávkou úloh a přeskoč spuštění, pokud nezbývá dost kapacity na její dokončení.

      • Vyber backend v kódu místo pevného zadání názvu.

      • Selhej rychle v pipeline a noteboocích místo čekání ve frontě.

    • Začínáme

      • Nejprve se ujisti, že používáš nejnovější verzi qiskit-ibm-catalog:

        pip install --upgrade qiskit-ibm-catalog

      • Poté se podívej do dokumentace pro více informací a příklad.

Třetí čtvrtletí

18. července 2025​

Šablony Qiskit Functions ti poskytují modulární pipeline, která umožňuje zaměnit nové nástroje, metody nebo konfigurace pro tvé vlastní experimenty. Všechny šablony funkcí jsou také snadno nasaditelné do Qiskit Serverless, kde můžeš snadno využít klasický výpočetní výkon jako součást spuštění svého workflow. Svůj serverless balíček můžeš nasadit ve svém preferovaném cloudovém prostředí, nebo využít hostovanou službu poskytovanou IBM pro uživatele plánů Premium a Flex. Bez ohledu na to, kterou možnost zvolíš, Qiskit Serverless pomáhá zjednodušit spouštění a paralelizovat části tvého workflow.

Podívej se na příručku Šablony Qiskit Functions, kde se dozvíš více, nebo si přečti přehled Qiskit Functions v dokumentaci.

Druhé čtvrtletí

5. června 2025​

  • S radostí uvádíme dvě nové funkce pro finance a optimalizaci:

    • QUICK-PDE od ColibriTD umožňuje uživatelům řešit určité diferenciální rovnice pro problémy deformace materiálu a výpočetní dynamiky tekutin. Například jeden tým výzkumníků už začal používat funkci QUICK-PDE ke studiu dynamiky nových reaktivních tekutin vyvinutých pro efektivnější přenos tepla v typu jaderného reaktoru známém jako Small Modular Reactors.

    • Quantum Portfolio Optimizer od Global Data Quantum umožňuje výzkumníkům v kvantitativních financích zpětně testovat strategie optimalizace portfolia. Tato funkce běží na více než 100 qubitech a počítá Sharpeho poměr portfolia v porovnání s výnosem za zadané časové období. Raní uživatelé zkoumají schopnost optimalizátoru vyhodnotit historickou výkonnost investiční strategie a umožnit porovnání různých portfolií za podobných podmínek.

Podívej se do Katalogu Qiskit Functions a vyžádej si dnes bezplatnou zkušební verzi.

16. května 2025​

  • V nadcházejících týdnech ti každá funkce poskytne podrobné informace, které ti pomohou spouštět, ladit a analyzovat tvé workflow. To zahrnuje:

    • Když úlohy selžou, můžeš pomocí job.error_message() najít konkrétní chybové kódy a zprávy, které ti pomohou s laděním workflow

    • job.status() poskytne více informací o tom, co se děje, zatímco je funkce ve stavu RUNNING, včetně:

      • RUNNING: MAPPING

      • RUNNING: OPTIMIZING_FOR_HARDWARE

      • RUNNING: WAITING_FOR_QPU

      • RUNNING: EXECUTING_QPU

      • RUNNING: POST_PROCESSING

    • Nakonec, po dokončení funkce Qiskit, můžeš zkontrolovat, kolik času bylo stráveno v jednotlivých fázích pomocí job.result()['metadata']['resource_usage'], jak ukazuje následující příklad.

Rozbalit ukázku kódu
{
      ...,
  "metadata": {
    "resource_usage": {
      {
        "RUNNING: MAPPING": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: OPTIMIZING_FOR_HARDWARE": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: WAITING_FOR_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: EXECUTING_QPU": {
          "CPU_TIME": seconds,
          "GPU_TIME": seconds,
          "QPU_TIME": seconds,
        },
        "RUNNING: POST_PROCESSING": {
          "CPU_TIME": seconds,

        },
      },
    }
  }
}

2024​

16. září 2024​

  • Představujeme náhled Qiskit Functions pro uživatele plánu IBM Quantum Premium. Pro začátek nainstaluj pip install qiskit-ibm-catalog a prozkoumej dokumentaci Qiskit Functions. S klientem Katalogu Qiskit Functions můžeš odesílat úlohy do abstrahovaných služeb navržených tak, aby urychlily tvůj výzkum. Přihlas se pomocí svých existujících přihlašovacích údajů IBM Quantum Platform.

    Náhled Katalogu Qiskit Functions poskytuje uživatelům plánu Premium přístup k prozkoumání dostupných funkcí, včetně těch napsaných IBM i těch napsaných dalšími členy našeho ekosystému. Katalog obsahuje dva druhy funkcí: funkce obvodů a aplikační funkce.

    • Funkce obvodů poskytují zjednodušené rozhraní pro spouštění obvodů. Přijímají jako vstup uživatelem zadané abstraktní obvody a pozorovatelné veličiny, poté řídí syntézu, optimalizaci a spuštění reprezentativního obvodu ISA. Funkce obvodů spojují nejnovější schopnosti v transpilaci, potlačení chyb a zmírnění chyb, aby byl výkon na úrovni utility dostupný ihned po instalaci. To umožňuje počítačovým vědcům soustředit se na mapování svých problémů na obvody místo budování vzoru pro každý problém od začátku.

    • Aplikační funkce pokrývají úlohy na vyšší úrovni, jako je zkoumání algoritmů a případů užití specifických pro danou doménu. Vývojáři v podnicích a datoví vědci nemusí mít znalosti z oblasti kvantové informační vědy potřebné pro práci s obvody a místo toho chtějí přinést své doménové znalosti k rozvoji kvantových algoritmů a aplikací. Díky aplikačním funkcím mohou uživatelé zadat klasické vstupy a získat řešení, aby mohli snadněji experimentovat s propojením kvantových výpočtů se svým doménově specifickým workflow.

  • Se spuštěním Katalogu Qiskit Functions mohou vývojáři s plánem Premium prozkoumat funkci IBM Circuit. Funkce IBM Circuit zahrnuje nejnovější rozšíření Qiskit poháněná umělou inteligencí pro syntézu, optimalizaci a plánování obvodů, stejně jako pokročilé metody zmírnění chyb, které vracejí nejpřesnější odhady možné s dnešním hardwarem.

    Uživatelé mohou zakoupit licence pro následující funkce od našich partnerů Q-CTRL, QEDMA a Algorithmiq.

  • Funkce obvodů

    • Q-CTRL uvádí funkci obvodu, která aplikuje techniky kvantového řízení poháněné umělou inteligencí, s jejichž pomocí mohou uživatelé úspěšně škálovat na větší problémy.

    • Algorithmiq uvádí funkci obvodu, která aplikuje TEM (zmírnění chyb pomocí tenzorové sítě), metodu zmírnění chyb pro získání odhadů s méně shoty než metoda PEC (pravděpodobnostní rušení chyb).

    • QEDMA uvádí funkci obvodu, která používá proprietární protokoly pro efektivní a přesnou charakterizaci šumových operací QPU a aplikuje potlačení a zmírnění chyb na základě dat charakterizace.

  • Aplikační funkce

    • Q-CTRL uvádí optimalizační řešič, kterému mohou uživatelé předat graf nebo cíl a získat náklady na řešení.
