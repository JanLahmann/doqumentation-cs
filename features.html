Funkce

doQumentation transformuje open-source obsah IBM Quantum do interaktivní vzdělávací platformy s živým spouštěním kódu, IBM Cloud Code Engine, režimem simulátoru, sledováním pokroku v učení a podporou 20 jazyků.

Automatická synchronizace ze zdroje

Obsah je automaticky synchronizován z repozitáře IBM na GitHubu, čímž jsou tutoriály a kurzy vždy aktuální s nejnovějšími verzemi Qiskitu. Last upstream content update: 2026-06-05 (commit 24c896a).

Strukturovaná navigace

Automaticky generované postranní panely se sbalitelnými kategoriemi. Tutoriály, průvodci, kurzy a moduly mají každý svůj vlastní organizovaný postranní panel.

Živé spouštění kódu

Přepínač Spustit / Zpět

Každá stránka s notebookem má tlačítko Spustit, které aktivuje všechny buňky kódu s živým kernelem Jupyter. Klikni na Zpět pro návrat do statického zobrazení.

Čtyři backend pro spouštění

Bezplatné vzdálené spouštění přes Binder nebo Google Colab, rychlé bezserverové kernely přes IBM Cloud Code Engine nebo plně offline přes Docker a RasQberry Pi. Když je dostupných více backendů, zvol který z nich se má použít na stránce Nastavení.

Zvolit backend →

IBM Cloud Code Engine

Bezserverový kernel Jupyter na tvém účtu IBM Cloud. Studený start trvá sekundy místo 10–25 minut u Binderu. Bezplatná úroveň pokryje přibližně 14 hodin měsíčně.

Nastavit Code Engine →

Režim workshopu

Pořádej workshopy s až 50 účastníky. Nasaď více instancí Code Engine a sdílej jednu URL — účastníci jsou automaticky rozděleni s lepivými relacemi a automatickým přepojením.

Průvodce nastavením workshopu →

Monitorování workshopů

Živý přehled s automatickým obnovením (30s) zobrazuje počty kernelů na instanci, zaneprázdněné kernely, připojení, využití paměti a provozuschopnost. Každá instance vystavuje endpoint /stats. Stresovací skript simuluje souběžné uživatele pro nalezení limitů kapacity před začátkem kurzu.

Přehled nastavení →

Otevřít v Google Colab

Každá stránka s notebookem má tlačítko „Otevřít v Colab” pro spouštění v cloudu bez instalace. Otevírá přeložené notebooky při procházení v jiném jazyce.

Zpětná vazba při spouštění buněk

Vizuální zpětná vazba na každé buňce: jantarový rámeček při běhu, zelený po dokončení, červený při chybě. Legenda se zobrazí v panelu nástrojů, když je kernel připraven.

Kontextové nápovědy k chybám

Automatická detekce ModuleNotFoundError, NameError a odpojení kernelu. Praktické nápovědy se zobrazí pod buňkou s navrhovanými řešeními. Každá chyba obsahuje odkaz „Nahlásit tuto chybu”, který otevře předvyplněný GitHub issue.

Instalace pip jedním kliknutím

Když je detekován chybějící balíček, zobrazí se klikatelné tlačítko „Nainstalovat”. Po dokončení instalace se buňka s chybou automaticky znovu spustí.

Otevřít v JupyterLab

Otevři libovolný notebook v plném JupyterLab. Spouštění Binderu zobrazuje sledování fází v reálném čase s časovačem a varováními při chybě cache. Zruš kdykoli nebo dostávej upozornění na pomalé fáze navrhující rychlejší backendy. Následná kliknutí okamžitě znovu použijí stejný server.

Spustit vše a restartovat

Spustit vše provede každou buňku v pořadí s aktivním čítačem průběhu. Kdykoli zastav po aktuální buňce. Restart ti dá nový kernel bez ztráty relace Binderu.

Integrace IBM Quantum

Úložiště přihlašovacích údajů

Ulož API token IBM Quantum a CRN jednou v Nastavení. Uloženo lokálně v prohlížeči s automatickým vypršením po 7 dnech z bezpečnostních důvodů.

Nastavit přihlašovací údaje →

Automatická injekce

Přihlašovací údaje jsou tiše injektovány do kernelu při spuštění. Nemusíš vkládat tokeny do každého notebooku — stačí kliknout Spustit.

Režim simulátoru

Spouštěj všechny notebooky bez účtu IBM Quantum. Zvol AerSimulator pro ideální simulaci nebo vyber z desítek FakeBackend modelujících šum skutečného zařízení. Žádné nastavení není potřeba.

Aktivovat simulátor →

Odznak režimu spouštění

Panel nástrojů zobrazuje, který režim je aktivní — název simulátoru (např. 'FakeSherbrooke') nebo 'IBM Quantum' — takže vždy víš, jak se tvůj kód spouští.

Učení a pokrok

Sledování pokroku

Navštívené stránky dostanou zaškrtnutí (✓) v postranním panelu. Spuštěné notebooky dostanou indikátor přehrávání (▶). Sleduj svou cestu obsahem.

Odznaky kategorií

Vyhledávání, uživatelské rozhraní a nasazení

Místní vyhledávání

Fulltextové vyhledávání na všech 381 stránkách, funguje offline. Výsledky se zobrazují okamžitě při psaní.

Tmavý režim

Plná podpora tmavého motivu. Diagramy obvodů a výstupy Matplotlib se automaticky invertují pro lepší čitelnost.

Vložená videa
