Simulace 127qubitového kicked Isingova modelu

V tomto průvodci používáme balíček pauli-prop ke klasické simulaci časové dynamiky 127qubitového kicked Isingova modelu na heavy-hex mřížce a k aproximaci magnetizace jednoho místa, ⟨Z62⟩\langle Z_{62} \rangle⟨Z62​⟩. Uvažovaný hamiltonián je:

H=−J∑⟨i,j⟩ZiZj+h∑iXiH = -J\sum\limits_{\langle i,j \rangle} Z_iZ_j + h\sum\limits_iX_iH=−J⟨i,j⟩∑​Zi​Zj​+hi∑​Xi​

kde J>0J>0J>0 popisuje vazbu mezi nejbližšími sousedními spiny, i<ji<ji<j, a hhh je globální příčné pole. Trotterův rozklad prvního řádu časově vyvinutého operátoru bude implementován jako kvantový obvod, UUU, o 202020 Trotterových krocích. Vazebná konstanta JJJ bude pevně nastavena na J=−π2J=-\frac{\pi}{2}J=−2π​, takže UUU je cliffordovský vždy, když hmod  π2=0h\mod\frac{\pi}{2}=0hmod2π​=0.

Pracovní postup:

  • Vytvoř kvantové obvody implementující trotterizovaný Isingův model

    • Měň hhh mezi Cliffordovými body, 0.00.00.0 a π2\frac{\pi}{2}2π​

  • Vyber místo uprostřed mřížky (qubit 626262) a odhadni magnetizaci po 202020 Trotterových krocích pro každý obvod

  • Pozoruj pokles magnetizace z 1.01.01.0 na 0.00.00.0, jak se hhh přesouvá z jednoho Cliffordova bodu do druhého

Vytvoření obvodů​

Nejprve použijeme FakeSherbrooke z qiskit-ibm-runtime, abychom získali indexy hran pro mapu propojení 127qubitového QPU Eagle. Jakmile máme indexy hran, vytvoříme Trotterovy obvody pro různé hodnoty hhh, které chceme simulovat. Obvody implementují trotterizaci hamiltoniánu prvního řádu s 20 Trotterovými kroky a 5420 hradly.

import numpy as np
from qiskit import QuantumCircuit
from qiskit_ibm_runtime.fake_provider import FakeSherbrooke

# Get the edges in the device coupling map
backend = FakeSherbrooke()
edges = backend.coupling_map.get_edges()

# Num Trotter steps
num_steps = 20

# Create Trotter circuits with varying global fields
hs = [i * np.pi / 32 for i in range(17)]
circuits = []
for h in hs:
    circuit = QuantumCircuit(backend.num_qubits)
    for _ in range(num_steps):
        circuit.rx(h, [i for i in range(backend.num_qubits)])
        for edge in edges:
            circuit.rzz(-np.pi / 2, edge[0], edge[1])
    circuits.append(circuit)

Simulace časové dynamiky pomocí Pauliho propagace​

Dále určíme observabli OOO, kterou chceme měřit. V tomto případě odhadujeme ⟨Z62⟩\langle Z_{62} \rangle⟨Z62​⟩.

Abychom prozkoumali magnetizaci mezi Cliffordovými body, přibližně propagujeme OOO na začátek obvodu UUU, čímž vznikne nová observabla O′≈U†OUO^\prime \approx U^{\dagger}OUO′≈U†OU.

Během propagace počet členů ve vyvíjené observabli roste exponenciálně s počtem hradel, takže je obvykle nutné omezit, jak velká může být. Zde omezujeme počet členů v O′O^\primeO′ na 10510^5105 a zkracujeme členy s koeficienty menšími než 10−510^{-5}10−5. Zkracování členů způsobuje určitou chybu. Jakmile máme O′O^\primeO′, můžeme snadno odhadnout střední hodnotu, ⟨0∣U†OU∣0⟩=⟨0∣O′∣0⟩\langle0|U^{\dagger}OU|0\rangle = \langle0|O^\prime|0\rangle⟨0∣U†OU∣0⟩=⟨0∣O′∣0⟩, sečtením koeficientů diagonálních členů v O′O^\primeO′ (členy sestávající na všech qubitech pouze z I nebo Z).

Nastavením frame='h' určujeme, že chceme observabli vyvíjet v Heisenbergově obraze (U†OUU^{\dagger}OUU†OU). Pro Schrödingerovu evoluci použij frame=s (UOU†UOU^{\dagger}UOU†).

import time

from pauli_prop import propagate_through_circuit
from qiskit.quantum_info import Pauli, SparsePauliOp

# Z_62 observable
id_pauli = Pauli("I" * backend.num_qubits)
observable = SparsePauliOp(id_pauli.dot(Pauli("Z"), [62]))

# Estimate the single-site magnetization for varying magnetic fields
times = []
approx_evs = []
for circuit in circuits:
    st = time.perf_counter()
    propagated_obs = propagate_through_circuit(
        observable, circuit, 100_000, 1e-5, frame="h"
    )[0]
    times.append(time.perf_counter() - st)
    approx_evs.append(
        float(
            propagated_obs.coeffs[~propagated_obs.paulis.x.any(axis=1)].sum()
        )
    )
print(f"Finished {len(circuits)} simulations in {sum(times):.0f}s")
Finished 17 simulations in 494s

Vizualizace​

Nakonec vykreslíme magnetizaci jako funkci hhh. Pro h=0h=0h=0 obvod neovlivňuje počáteční stav ve výpočetní bázi a víme, že ⟨0∣O∣0⟩=1.0\langle0|O|0\rangle = 1.0⟨0∣O∣0⟩=1.0. S rostoucí vzdáleností hhh od 000 magnetizace monotónně klesá, dokud hhh nedosáhne dalšího Cliffordova úhlu, π2\frac{\pi}{2}2π​, a magnetizace nezkonverguje k 000.

import matplotlib.pyplot as plt

plt.xlabel(r"$R_x$ angle $\theta_h$")
plt.ylabel(r"$\langle Z_{62} \rangle$")
plt.plot(hs, approx_evs, marker="o")
